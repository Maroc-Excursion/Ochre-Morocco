تحديث التوكن المشفر المحفوظ في متصفحك

تحديث GitHub Token

التوكن محفوظ مشفراً في متصفحك باستخدام AES-256. لا أحد يستطيع رؤيته حتى لو فتح الكود المصدري. أدخل توكناً جديداً إذا أردت تغييره أو إذا انتهت صلاحيته.

كيف تحصل على توكن؟
1. اذهب إلى: github.com → Settings → Developer settings → Fine-grained tokens
2. Generate new token → اختر المستودع Ochre-Morocco فقط
3. الصلاحيات المطلوبة: Repository permissions → Contents → Read and write
4. انسخ التوكن وضعه هنا
