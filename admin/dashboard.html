Email Setup

EmailJS Configuration

EmailJS lets you send booking confirmations directly from the browser — no backend needed.
Setup: Create a free account at emailjs.com, add your email service (Gmail / Outlook), create two templates (ownerTpl and clientTpl), then paste your IDs below into assets/js/booking.js.

enabledfalse → true once IDs are set publicKeyYour EmailJS public key (Account → API Keys) serviceIdEmail service ID (e.g. service_abc123) ownerTplTemplate that notifies you of new bookings clientTplTemplate sent to the customer as confirmation

Edit assets/js/booking.js lines 5–16 and replace YOUR_PUBLIC_KEY etc. with your real IDs, then set enabled: true.

Payment Links (Stripe)

Create a Stripe Payment Link for each service and paste the URL in assets/js/booking.js under payLinks. Leaving a service URL empty routes the customer to WhatsApp instead.

'airport-transfer': '' → paste Stripe URL here
'agafay-desert-pack': '' → paste Stripe URL here
…one entry per service in booking.js
